# 移动端餐次采购量切换 QA

## 检查范围

- 页面：`school-mobile.html`
- 场景：需求填报、确认需求
- 参考：用户提供的移动端餐次切换标注截图；复用 Web 端 `mealRows` 餐次计算逻辑

## 已检查结果

- 需求填报页在餐次就餐人数卡片下方显示早餐、午餐、晚餐切换 Tab。
- 切换餐次后，采购商品列表和采购量显示对应餐次的数据，不再显示所有餐次汇总。
- 确认需求页将学生/其他订单标签放在上方，餐次切换 Tab 放入采购商品卡片内，位于“采购商品”标题上方。
- 确认需求页切换餐次后，采购商品、采购量和单价区域正常更新。
- 采购量编辑状态按“餐次 + 商品 + 人员类型”保存，提交时可按餐次传递。
- 已通过本地移动端预览检查；未执行大规模测试。

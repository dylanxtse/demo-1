学校端

涉及功能食谱中心
描述

1. 接收营养平台按用料日期同步的食谱，学校端只展示已同步且可用于采购的食谱；
2. 按用料日期查看早餐、午餐、晚餐等餐次，以及每个餐次对应的菜品；
3. 查看菜品关联的食材和采购商品信息，为后续需求计算提供数据依据；
4. 从指定用料日期进入需求填报，确保填报人数与对应日期、餐次和食谱保持一致。

涉及功能需求填报
描述

1. 按用料日期和餐次分别填写学生、教师就餐人数，两个人员类型独立录入、独立校验；
2. 在未填写人数前，商品需求列表保持为空，避免展示无法确认数量的采购商品；
3. 填写人数后，根据食谱中的食材与商品关联关系，以及营养平台维护的人均用量，自动计算学生需求量、教师需求量和需求总量；
4. 按餐次展示本次实际需要采购的商品，并将来源食材、采购商品、商品编号、单位和各人员类型需求量分开显示；
5. 支持修改人数后实时重新计算需求，填报完成后进入需求确认。

涉及功能需求确认
描述

1. 汇总当前选择的单日或多日用料日期需求，集中查看各日期的商品需求总量；
2. 支持展开某个用料日期，查看该日期下各餐次的学生人数、教师人数和合计人数；
3. 商品需求明细按来源食材在前、采购商品在后分字段展示，并区分学生需求量、教师需求量和需求总量；
4. 提交前允许手动选择需要下单的一个或多个用料日期，并在确认弹窗中展示本次需求包含的用料日期和期望送达日期；
5. 确认后按人员类型生成对应订单，学生和教师订单通过订单标签进行区分。

涉及功能提交记录
描述

1. 记录每次需求提交的用料日期、学校、食堂、操作人、提交时间、商品品种数和生成订单数；
2. 列表支持按用料日期查询，并展示本次提交包含的用料日期范围和需求汇总；
3. 详情页展示关联订单，按学生、教师订单标签区分对应订单；
4. 用料日期明细支持展开查看该日期下早餐、午餐、晚餐的学生人数、教师人数和合计人数；
5. 商品需求明细展示来源食材、采购商品、商品编号、单位、学生需求量、教师需求量和需求总量，来源食材字段在前、采购商品字段在后；
6. 提交记录作为需求计算和下单结果的留痕，支持从列表进入详情查看完整填报人数与商品需求明细。
